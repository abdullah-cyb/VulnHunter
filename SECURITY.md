# Security Policy

## Reporting Vulnerabilities

ABDULLAH.CYB takes the security of our security tools seriously. If you discover a vulnerability or flaw in **VulnHunter**, please report it responsibly.

### Disclosure Process
1. Email details to `security@abdullah.cyb`.
2. Do not disclose the issue publicly until a fix has been released.
3. Our team will acknowledge receipt within 24 hours.

## Authorized Assessment Guidelines
Users are reminded that **VulnHunter** must only be executed against infrastructure and target hosts for which explicit, written permission has been obtained. Unauthorized scanning may violate computer crime laws in your jurisdiction.
